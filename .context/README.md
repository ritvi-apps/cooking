# .context

hamburg's product material, written in Plain Context. Wiki rules: `.claude/rules/wiki.md`.
The repository is named `cooking`. It holds no application code, only content and a
design set, so the design set is the spec.

## Start here

1. [`wiki/concepts/purpose.md`](wiki/concepts/purpose.md): what hamburg is, who it is for, what it is not.
2. [`wiki/concepts/glossary.md`](wiki/concepts/glossary.md): hamburg's own words.
3. [`wiki/index.md`](wiki/index.md): every concept, decision and surface, one line each.
4. [`tasks.md`](tasks.md): what to do next.

## Where things are

| Folder | Holds |
|---|---|
| `wiki/` | Concepts, decisions, entities and surfaces |
| `problems/` · `ideas/` · `experiments/` · `features/` · `bugs/` | Work records |
| `designs/` | The design set; open `designs/web/index.html` from disk. The brand mark is the `.brand-mark` class |
| `architecture/` | How the repo is built (`architecture.json`) |
| `raw/` | Sources, never edited |
