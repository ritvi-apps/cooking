## Summary
Cook it. If it was good, save it. If it was not, still note why.

## Why it matters
**The site only holds what was cooked.** The README calls this the growth rule,
and Recipes repeats it: dishes cooked and liked, not a wishlist.

## Implications
- A recipe is added after it is cooked, never before.
- An ingredient gets a page the first time a recipe uses it.
- A recipe page keeps notes for next time, including what went wrong.
- The cookbook holds one recipe today, and that is correct.
