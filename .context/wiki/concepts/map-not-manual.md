## Summary
hamburg is a map of what an ingredient can become, not a manual of recipes.

## Why it matters
**The owner has a poor memory.** The README opens with it. A recipe has to be
hunted for; a map is opened for whatever is on the counter, and a path is
picked. Journeys says the same thing in its own words.

## Implications
- Every raw ingredient has a journey: a graph of what it can become.
- Every node in a graph is a link.
- A step page is big numbered steps with little text.
- The site is not documentation. A page that reads like a manual is wrong.
