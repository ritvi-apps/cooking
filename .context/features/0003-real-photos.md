# Real photos in place of emoji

## Summary
Replace the emoji glyphs with the owner's own photos.

## Motivation
The README says emoji glyphs stand in for photos until real ones are taken. Every tile, hero and node in the set is an emoji today.

## Acceptance scenarios
- Given an ingredient the owner has photographed, then its tile and hero show the photo.
- Given one that has no photo yet, then it still shows its emoji.

## Out of scope
Stock photography.

## Open questions
- Where do the photos live? `designs/brand/` is for the product's own artwork, and there is none yet.
