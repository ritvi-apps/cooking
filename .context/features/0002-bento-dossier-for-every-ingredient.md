# A bento dossier for every ingredient

## Summary
Redraw the six older dossiers in the single-frame bento shape Tomato has.

## Motivation
Tomato was redrawn on 2026-07-19 because the chapter layout was too text-dense ([[2026-07-19-bento-dossier]]). Paneer, Spinach, Ginger, Garlic, Cumin and Garam masala still use the older page. [[ingredient-dossier]] lists the three shapes the set draws.

## Acceptance scenarios
- Given any dossier, then it fits one 1440 × 900 frame with no scroll.
- Given any dossier, then its tiles are the same five as Tomato's.
- Given Home, then a tile no longer says "7 chapters".

## Out of scope
Grow guides for the other six. Only Tomato has one.

## Open questions
- Do a spice and a blend have a Grow tile?
